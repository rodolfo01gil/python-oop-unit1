# Unit 1: Python Object-Oriented Programming

## Overview

This project demonstrates fundamental object-oriented

programming concepts using Python.

## Concepts Demonstrated

- Parent and child classes

- Inheritance and method overriding

- Class and instance variables

- Class and instance namespaces

- Shallow copying

- Deep copying

## Student Extension

The program includes an enroll_course() method that

allows student objects to add courses to their records.

## Running the Program

Run the following command:

python unit1_oop.py
